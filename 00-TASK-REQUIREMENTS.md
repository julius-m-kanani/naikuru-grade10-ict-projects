# GRADE 10 ICT PROJECT — TASK REQUIREMENTS
## Naikuru P.A.G Secondary School | 2026 | 50 Marks

**Theme: USING PRODUCTIVITY TOOLS**
**Community Service Learning: solve a real-life problem in the school or locality using (a) word processor, (b) spreadsheet, (c) presentation software.**

Suggested problems: waste management, environmental conservation, health and safety awareness,
time management among learners, road safety, small business record keeping.

---

## Instructions to the Learner

(i) Work in groups of **up to 5 members** as directed by your teacher. Each member must participate actively in each task.
(ii) This practical consists of **four tasks**. Do all of them on the SAME problem.
(iii) Complete all tasks within the given time. Check accuracy and completeness before submission.
(iv) Prepare a **soft copy** of all completed tasks and submit to your teacher using the method provided. Files must be well organised and correctly named.
(v) The project is assessed out of **50 marks**: Task 1 = 13, Task 2 = 21, Task 3 = 14, Task 4 = 2.

| Task | Maximum Score |
|---|---|
| 1 – Collecting and analysing information | 13 |
| 2 – Report writing | 21 |
| 3 – Presentation | 14 |
| 4 – File management | 2 |
| **Total** | **50** |

## TASK 1: Collecting and analysing information (13 marks)

Collect and analyse information about your chosen problem by doing the following in turn:

1. **Identify** a problem in your school or community.
2. **Collect information** about the problem from **at least 20 participants** (use the sample questionnaire in `samples/task1-collect-analyse/questionnaire.md` as a starting point).
3. Using **spreadsheets**, do the following:
   - (a) Enter the information collected into a worksheet, capturing headings and labels. See `waste-management-survey-20-respondents.csv`.
   - (b) Use **formulas and functions** to analyse the information. Minimum: `SUM`, `AVERAGE`, `COUNT`, `COUNTIF`, `MAX`, `MIN`, `IF`. See `analysis-steps.md`.
   - (c) Create **at least one chart or graph** from the analysed information (e.g. bar chart of waste types, pie chart of disposal methods).
   - (d) **Save** the worksheet as: `GroupXX_Task1_Spreadsheet.xlsx` (e.g. `Group03_Task1_Spreadsheet.xlsx`).

**Evidence to submit:** the spreadsheet file (.xlsx / .ods / Google Sheet link exported) + chart.

---

## TASK 2: Report writing (21 marks)

Prepare a report on the findings in Task 1 by doing the following in turn:

1. Using a **word processor**, prepare a report that includes:
   - (a) Title and introduction.
   - (b) Description of the problem.
   - (c) Causes of the problem **in bullets**.
   - (d) Effects of the problem **with at least one image**.
   - (e) Proposed solutions **summarised in a table**.
   - (f) Appropriate conclusion.
   - A full sample is provided: `samples/task2-report-writing/sample-report.md`.
2. **Format** the document as follows:
   - (a) Use headings (Heading 1, Heading 2).
   - (b) Apply different font styles (e.g. bold, italic, underline, sizes).
   - (c) Apply appropriate line spacing (e.g. 1.15 or 1.5).
   - (d) Use different alignment styles (left, centre, justify).
3. **Generate a table of contents** for the report (References > Table of Contents in Word/LibreOffice).
4. **Save** the report as: `GroupXX_Task2_Report.docx` (e.g. `Group03_Task2_Report.docx`).
5. Use **mail merge** to share the project report with **at least ten classmates**. Template + recipient list are in `samples/task2-report-writing/`.
6. **Save the personalised mail merge letters as a separate document**: `GroupXX_Task2_MailMerge.docx`.

**Evidence to submit:** report file + mail-merge letters file.

---

## TASK 3: Presentation (14 marks)

Prepare a presentation by doing the following in turn:

1. Using presentation software, create **five to eight slides** summarising:
   - (a) Title of the problem.
   - (b) Problem description.
   - (c) Key findings including a chart or graph (reuse chart from Task 1).
   - (d) Proposed solutions.
   - (e) Conclusion.
   - Follow `samples/task3-presentation/presentation-outline.md` (6-slide sample).
2. Apply the following:
   - (a) Slide designs (theme / background).
   - (b) Transitions (e.g. Fade, Push).
   - (c) Animations (e.g. Appear, Fly In — do not over-animate).
3. **Save** as: `GroupXX_Task3_Presentation.pptx`.
4. Make **oral presentations** to the school community (class / assembly / club). Each member must speak.

**Evidence to submit:** presentation file + oral presentation (teacher to confirm).
