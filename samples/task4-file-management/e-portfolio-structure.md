# Task 4 — E-Portfolio Structure & File Naming

Create ONE folder per group. Example for Group 03:

```
Grade10_ICT_Group03_2026/
  Group03_Task1_Spreadsheet.xlsx   (from CSV sample, with formulas + chart)
  Group03_Task2_Report.docx        (formatted report + TOC + image + table)
  Group03_Task2_MailMerge.docx     (at least 10 personalised letters)
  Group03_Task3_Presentation.pptx  (5–8 slides + design/transitions/animations)
```

### Rules
1. Folder name: `Grade10_ICT_GroupXX_2026` (replace XX with your group number).
2. File names exactly as above — check capitalisation and underscores.
3. No subfolders, no loose photos outside files, no `Document1.docx`.
4. Zip the folder only if submitting online: `Grade10_ICT_Group03_2026.zip`.
5. Submit via the method your teacher gives (USB / lab PC / Drive).

### Pre-submit check (open each file once)
- Spreadsheet opens, formulas recalc, chart visible.
- Report opens, TOC clickable, image visible, no red underlines on headings.
- Presentation plays slideshow end-to-end.
