# Sample Questionnaire — Waste Management at Naikuru P.A.G Secondary
## Adapt this for your group's problem. Collect from at least 20 participants.

Group: ______ Date: ______ Collector: ______

1. Name (optional): ________________ Class / Role: _________ (Student / Teacher / Worker / Parent)
2. What type of waste do you see MOST around the school? (tick one)
   [ ] Plastic bottles/papers  [ ] Food waste  [ ] Compound waste (leaves/dust)  [ ] E-waste / metals  [ ] Other: ______
3. How do you USUALLY dispose of litter?
   [ ] School bin  [ ] Pit  [ ] Burning  [ ] Throw on ground  [ ] Carry home
4. How many days per week is your classroom / area cleaned? (0–7): ______
5. Rate cleanliness of the school compound (1 = very dirty, 5 = very clean): ______
6. Main CAUSE of poor waste disposal? (tick one)
   [ ] Few bins  [ ] Bins far  [ ] No awareness  [ ] Laziness / attitude  [ ] Collection delay
7. Main EFFECT you have observed? (tick one)
   [ ] Bad smell  [ ] Flies / disease  [ ] Blocked drainage  [ ] Poor school image  [ ] Animals scattering litter
8. Suggested SOLUTION? (tick one)
   [ ] More bins + sorting  [ ] Duty rota + prefects  [ ] Awareness club  [ ] Compost pit / recycling  [ ] Fine / reward system

Thank you for participating!

### How to record answers (for spreadsheet entry)
