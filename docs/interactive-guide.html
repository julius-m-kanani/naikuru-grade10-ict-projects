Task 1 — Collecting and analysing data
13 marks · Spreadsheet · At least 20 participants
Your progress in Task 1
Step 1 of 4
1
Identify your problem and design a survey
Based on your chosen topic, write 3–5 short questions that will help you understand the problem. At least one question should have a yes/no or number answer so you can count responses easily.
Example (Waste Management):
Q1. How many days per week do you see litter in school? (0 / 1–2 / 3–4 / 5+)
Q2. Are there enough dustbins in your class? (Yes / No)
Q3. Have you ever littered at school? (Yes / No / Sometimes)
Your survey questions
2
Collect data from at least 20 participants
Walk around school during break time. Ask at least 20 different people your questions and write their answers on paper first. Split the work among your group members — each person can interview 4–5 people.
Don't forget: You need a minimum of 20 responses. The examiner checks the number of rows in your spreadsheet.
3
Enter your data in a spreadsheet
Open Microsoft Excel (or LibreOffice Calc). Row 1 is your headings. Each row below is one person's responses. Then use formulas to summarise.

Create a chart and save your file
Select your data columns, then go to Insert → Chart. Choose a bar chart or pie chart. Give it a title and label the axes. Then save as: Task1_[Topic]_Data.xlsx
✅ When done: Your spreadsheet should have at least 20 rows of data, visible formulas in a summary section, and a chart. Save and close before moving to Task 2.

Waste management is a growing concern in many Kenyan schools. This report investigates the problem of poor waste disposal at Naikuru Secondary School, examines its causes and effects, and proposes practical solutions that can be implemented by the school community.

2
Apply formatting
The examiner checks these 4 formatting elements specifically. Apply all of them.
📌 Headings
Select each section title → Home → Styles → Heading 1 or Heading 2
🔤 Font styles
Title: bold 16pt. Body: regular 12pt. Try using a different font for headings vs body text
↕ Line spacing
Home → Line Spacing → 1.5 for body text. Double spacing for the abstract/intro
⬛ Alignment
Title: Center. Body: Justify. Section headings: Left align
3
Generate a Table of Contents
This only works if you applied Heading styles in Step 2. Once you have, place your cursor after the title page, then:
Microsoft Word
Step 1: Click where you want the Table of Contents
▶ Click at the top of page 2 (after title page)
Step 2: Insert it from the menu
References → Table of Contents → Automatic Table 1
Step 3: Update if you add more content later
Right-click the TOC → Update Field → Update entire table
4
Do the Mail Merge
Mail merge creates personalised copies of your report letter for each classmate. This is worth marks — do not skip it.
Mail Merge Wizard
Step 1: Create your recipient list (Excel file)
Save a file: Classmates_List.xlsx
Columns: FirstName | LastName | AdmNumber
Add at least 10 classmates' names
Step 2: Start mail merge in Word
Mailings → Start Mail Merge → Letters
Mailings → Select Recipients → Use Existing List → choose your Excel file
Step 3: Insert merge fields in the letter
Type: Dear «FirstName» «LastName»,
Use Insert Merge Field to add the field names
Step 4: Complete and save merged letters
Finish & Merge → Edit Individual Documents → All
Save as: Task2_MailMerge_Letters.docx
Save TWO files: (1) your original report, (2) the merged letters as a separate document. You lose marks if only one file is saved.
5
Save both files with correct names
Use clear, descriptive file names. Avoid "Document1" or "Untitled".
✅ Report file: Task2_[Topic]_Report.docx
✅ Mail merge file: Task2_[Topic]_MailMerge.docx
Both go into your project folder for Task 4.

Time management is one of the most critical skills for academic success. This report investigates the challenge of poor time management among Grade 10 learners at Naikuru Secondary School, based on a survey conducted in September 2026 with 22 participants.

Final submission checklist
Go through every item before submitting your e-portfolio. Tick each one when done.
📋 Task 1 — Spreadsheet
  • Data from at least 20 participants entered with headings and labels
  • At least 3 different formulas used (SUM/AVERAGE, COUNTIF, MAX/MIN or %)
  • One chart or graph created and titled
  • File saved as Task1_[Topic]_Data.xlsx inside the project folder
📝 Task 2 — Report
  • Report has all 6 sections: Title, Introduction, Problem, Causes (bullets), Effects (with image), Solutions (table), Conclusion
  • Heading styles applied (Heading 1 / Heading 2)
  • At least 2 different font styles used
  • Line spacing set (1.5 or double for body text)
  • At least 2 alignment styles used (e.g. centred title + justified body)
  • Table of contents generated (not typed manually)
  • At least one image inserted in the Effects section
  • Mail merge done with at least 10 classmates
  • Report saved: Task2_[Topic]_Report.docx
  • Merged letters saved separately: Task2_[Topic]_MailMerge.docx
📽 Task 3 — Presentation
  • Exactly 5–8 slides created
  • All 5 required content sections present (title, description, findings with chart, solutions, conclusion)
  • A slide design/theme applied (not plain white)
  • Slide transitions added to all slides
  • At least one animation added to slide content
  • Presentation saved: Task3_[Topic]_Slides.pptx
  • Group is ready for oral presentation
🗂 Task 4 — File management
  • One folder created with a clear name (Group_Topic_Project)
  • All task files (spreadsheet, report, merged letters, slides) are inside the folder
  • Folder submitted using the teacher's specified method (USB / Drive / network)
