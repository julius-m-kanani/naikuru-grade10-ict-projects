General Steps (all projects)

  1. Task 1 (13): Identify problem → survey 20 people → enter in spreadsheet with headings → use SUM, AVERAGE, COUNT, COUNTIF, MAX, MIN, IF → 1 chart → save GroupXX_Task1_Spreadsheet.xlsx
  2. Task 2 (21): Word report: title, intro, description, bulleted causes, effects + 1 image, solutions table, conclusion → headings, fonts, spacing, alignment → auto Table of Contents → mail merge to 10 classmates → save GroupXX_Task2_Report.docx + GroupXX_Task2_MailMerge.docx
  3. Task 3 (14): 5–8 slides: title, description, findings + chart, solutions, conclusion → design + transitions + animations → oral presentation → save GroupXX_Task3_Presentation.pptx
  4. Task 4 (2): One folder Grade10_ICT_GroupXX_2026 with all 4 files. Submit.
