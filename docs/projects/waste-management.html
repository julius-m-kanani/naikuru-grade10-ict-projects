Overview & Objectives

Problem: Plastic/papers behind classes, food waste attracting flies, delayed collection. Sample cleanliness rating 2.75/5; only 40% use bins.

Objectives: measure disposal habits (n=20), analyse causes/effects, propose low-cost fixes (bins, rota, club, compost).

Task 1 — Collect & Analyse (13)

  1. Adapt questionnaire: CommonWaste? DisposalMethod? CleaningDays (0–7)? Rating (1–5)? Cause? Effect? Solution?
  2. Survey 20 people (learners, teachers, workers, parents). See ../samples/task1-collect-analyse/ CSV sample.
  3. Enter with headings: RespondentID, Class_Role, CommonWaste, DisposalMethod, CleaningDaysPerWeek, CleanlinessRating, MainCause, MainEffect, SuggestedSolution.
  4. Formulas (data rows 2–21):
    =COUNTA(A2:A21) total • =AVERAGE(E2:E21) avg days • =AVERAGE(F2:F21) avg rating • =COUNTIF(C2:C21,"Plastic") • =COUNTIF(D2:D21,"Bin")/COUNTA(A2:A21)*100 % bin use • =IF(F2<=2,"Needs attention","OK")
  5. Charts: bar of waste types (Plastic 10, Food 6, Compound 4) + pie of disposal (Bin 8, Pit 5, Ground 4, Burning 2, CarryHome 1).
  6. Save GroupXX_Task1_Spreadsheet.xlsx.

Task 2 — Report (21)

  1. Sections: Title+Intro → Description (rating 2.75, 40% bin use) → Causes (bullets: few bins, distance, awareness, attitude, delays) → Effects + 1 photo → Solutions table → Conclusion.
  2. Solutions table: 10 labelled bins | duty rota | environment club Fridays | compost pit + recycling | cleanest-class award.
  3. Format: Heading 1/2, bold/italic, 1.15 spacing, centred title + justified body, auto TOC.
  4. Mail merge letter to 10 classmates using recipient CSV → save GroupXX_Task2_MailMerge.docx.

Task 3 — Presentation (14)

  1. 6 slides: Title → Description → Findings+chart → Causes/Effects → Solutions → Conclusion + call to action.
  2. Theme, transitions (Fade/Push), one animation per slide, 24pt+ text, chart takeaway: "6 in 10 don't use bins."
  3. Oral: each member speaks ~1 min. Save GroupXX_Task3_Presentation.pptx.

Task 4 — E-portfolio (2)

Folder Grade10_ICT_GroupXX_2026 with spreadsheet + report + merge letters + presentation. Check each opens.

Checklist

  • ☐ 20 rows + 4+ formulas + 1 titled chart
  • ☐ Report has bullets, image, table, TOC, merge to 10
  • ☐ 5–8 slides + oral done
  • ☐ One correctly named folder
