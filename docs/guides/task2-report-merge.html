Step A — Structure (paste from builder, 10 min)

  1. New document → paste 6 sections: Title, Introduction, Description, Causes, Effects, Solutions, Conclusion.
  2. Causes → select → Bullets. Solutions → Insert → Table (5 cols: #/Solution/Who/When or Cost).
  3. Effects → Insert → Picture (your photo, faces blurred) → right-click → Insert Caption ("Figure 1: …").

Step B — Format (10 min, examiners check each)

  1. Select section titles → Heading 1 (Styles). Sub-points → Heading 2.
  2. Title: 18pt Bold Centred. Body: 12pt, 1.15/1.5 spacing (Paragraph → Line spacing), Justified.
  3. Bold + italic + one colour somewhere (e.g. key stat 40%).
  4. Caption: centred, 10pt italic.

Step C — Table of Contents (2 min, must be automatic)

  1. Top of doc → blank page → References → Table of Contents → Automatic (Writer: Insert → TOC/Index).
  2. Right-click TOC → Update Field before saving. Typed TOC = 0 marks.
  3. File → Save As GroupXX_Task2_Report.docx.

Step D — Mail merge to 10 classmates (10 min)

  1. Word: Mailings → Start Mail Merge → Letters → Select Recipients → Use Existing List → your recipient CSV (12 names provided in repo) → place cursor → Insert Merge Field → FirstName, LastName, Class → Finish & Merge → Edit Individual Documents → All.
  2. Writer: Tools → Mail Merge Wizard → select CSV → insert fields → save merged.
  3. Save output as GroupXX_Task2_MailMerge.docx (must show 10+ personalised letters — "Dear Brian Kiprop (Form 1A)…").

Template letter + CSV: see repo samples/task2-report-writing/ or homepage templates.
