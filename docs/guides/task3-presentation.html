PowerPoint • LibreOffice Impress • Google Slides — recreate the examples click-for-click

See first, then build

Open an example that matches PowerPoint: Waste • Road • Time • Environment/Health/Business. Yours must have 5–8 slides in this order: Title → Description → Findings+chart → Causes/Effects → Solutions → Thanks.

Step A — Slides (15 min)

  1. Design tab → pick one theme (e.g. Facet/Office) → keep for ALL slides. 24pt+ body, high contrast.
  2. New Slide ×6 (Title Slide, then Title+Content). Paste text short — speak the detail.
  3. Slide 3: copy chart from Excel → in PowerPoint Paste → Picture (so it never breaks). Add takeaway line.
  4. Insert → Header/Footer → Slide numbers ON.

Step B — Transitions + animations (5 min, all required)

  1. Transitions tab → Fade (slides 1–3), Push (4–6) → Apply To All (Impress: Slide Transition panel).
  2. Animations tab → select bullets/chart → Appear / Wipe / Fly In. ONE per slide max — examiners deduct for chaos.
  3. Slide Show → From Beginning → check order + timing (6–8 min total).

Step C — Oral (each member speaks)

Roles: 1 greets, 2 problem, 3 chart ("6 in 10…"), 4 solutions, 5 concludes + Q&A. Cards, not reading slides. Teacher ticks participation.

Step D — Save

File → Save As GroupXX_Task3_Presentation.pptx (.pptx even from Impress/Slides: File → Download).
