Build Guide — Task 1: Spreadsheet (13 marks)

Excel • LibreOffice Calc • Google Sheets — same clicks, different names

What the examiner sees

Headings + 20 rows + 4+ functions + 1 titled chart + correct filename. Miss one = lose marks.

Step A — Create file (2 min)

  1. Download starter CSV for your problem (see homepage templates).
  2. Excel: File → Open → CSV → File → Save As → GroupXX_Task1_Spreadsheet.xlsx.
    Calc: same, save as .xlsx (keep Excel format for marking).
    Sheets: File → Import → Upload → File → Download → .xlsx before submitting.
  3. Rename Sheet1 → RawData. Add sheets Analysis, Charts (right-click tab → Rename/Insert).

Step B — Format headings (3 min)

  1. Select row 1 → Bold → Centre → Fill colour.
  2. View → Freeze Top Row (View → Freeze Rows/Columns in Calc).
  3. Select all data → Borders → All Borders. Set rating columns to Number, 1 decimal for averages.

Step C — Analysis formulas (10 min, copy-paste)

In Analysis sheet, type label in A, formula in B (data in RawData!A2:A21):

Label (A)Formula (B)
Total=COUNTA(RawData!A2:A21)
Average=AVERAGE(RawData!F2:F21)
Max / Min=MAX(RawData!E2:E21) / =MIN(RawData!E2:E21)
Count answer=COUNTIF(RawData!D2:D21,"Bin") (change Bin to your answer)
Percent=COUNTIF(RawData!D2:D21,"Bin")/COUNTA(RawData!A2:A21)*100
Flag=IF(RawData!F2<=2,"Needs attention","OK") → drag down

Business: =C2*D2 (Total), =E2-F2 (Profit), =SUM(G2:G8) (week).

Step D — Chart (5 min)

  1. In Analysis make mini table: Answer | Count (e.g. Walking 11, Boda 6, Matatu 3).
  2. Select table → Insert → Column Chart (bar) or Pie.
  3. Chart Title (e.g. "Travel to school, n=20") → Add Data Labels → Axis Titles.
  4. Cut → paste into Charts sheet. Write one takeaway below: "Only 40% use bins."
