# TEACHER GUIDE — Supervising the Grade 10 ICT Project
## Naikuru P.A.G Secondary | 2026

### 1. Grouping (Week 1)
- Groups of up to 5. Mix abilities. Approve group lists.
- Assign group numbers: Group01, Group02 … Use them in all file names.
- Assign each group a problem (avoid all groups picking waste management; spread across the 6 suggested areas).

### 2. Suggested 6-Week Timeline
- **Week 1:** Launch, group, choose problem, adapt questionnaire.
- **Week 2:** Data collection from 20+ participants (classmates, teachers, community). Enter into spreadsheet.
- **Week 3:** Spreadsheet analysis + chart. Teacher checks Task 1 draft.
- **Week 4:** Word report + formatting + table of contents + images.
- **Week 5:** Mail merge + presentation slides + rehearsal.
- **Week 6:** Oral presentations + e-portfolio submission + marking.

### 3. Lab / Resource Notes
- LibreOffice (free) is fine where MS Office is unavailable. Google Sheets/Docs/Slides also accepted — export to .xlsx/.docx/.pptx before submission.
- Phones may be used for photos (effects image) and data collection; transfer to lab PCs for typing.
- Keep a backup USB / Drive folder per group.

### 4. Integrity
- Each member must participate in each task. Ask random oral questions to confirm.
- Images must be original (school compound) or cited. No copying another group's data.
- Mail merge must show at least 10 distinct recipients.

### 5. Submission Method (pick one and tell learners)
- Option A: One zipped folder per group uploaded to teacher's laptop / Google Drive.
- Option B: Shared school computer folder `Grade10_ICT_2026/Grade10_ICT_GroupXX_2026`.
- Check: 4 files minimum (spreadsheet, report, mail-merge letters, presentation) in one folder.

### 6. Moderation
- Use MARKING-SCHEME.md. Record scores in the supervisor table.
- Keep samples of best / average / weak e-portfolios for KNEC readiness.
